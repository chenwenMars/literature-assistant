# MBA 论文精读与写作学习设计

## 目标与授权
用户已确定《AI赋能的T公司采购系统研发项目管理研究》，AI用于辅助项目管理，研究保持在MBA项目管理范畴。目前尚未设计研究，需要吸收其他论文的构思、方法和写法。用户明确授权“后续都同意你的意见，请完成项目的代码改造”，本次自行完成设计、实施与验证。

## 报告
复用Markdown输出，六个二级章节依次为：阅读概览、整体构思、逐章写作拆解、研究方法拆解、关键论证与写法、我的借鉴笔记。第三、四部分为主体。原文陈述、分析判断、写作建议分别标记；事实、关键结论和范例关联真实来源片段。信息不足时缩短分析，不补造章节、数据或企业情况。研究关注MBA项目管理与AI辅助管理；其他主题忠实分析，只说明适用的写作借鉴，不强贴AI或敏捷标签。方法选择保持开放，正式论文撰写和多文献综合不在本轮范围内。

## 原文与导入
解析返回SourceDocument，含blocks（id、label、text）和warnings。PDF逐页读取，标签明确是文件页序；DOCX按正文顺序读取段落与表格，嵌套表格递归保留；Markdown保留原始标题及表格。图片、公式及OCR能力边界显式说明。完全无文字的文件抛出解析异常，不请求AI。片段用S1等稳定编号，输入模型为“[S1] 标签”及文字，模型输出链接为[S1](#source-S1)。不允许引用不存在的来源编号。
新文献保存source_document快照和report_version。历史报告完整保留；未保存原文的历史文献可显式重新解析，其来源编号不被宣称为旧报告的生成依据。原文获取单独接口，避免列表和详情携带全文。

## 完成与失败
AI生成必须具有finish_reason=stop、非空正文和完整结束事件；长度截断、断流、上游错误均失败。数据库保存只由成功结果触发，不使用SSE连接关闭作为成功信号。批量文件完成包含分类完成；分类失败保存阅读报告并显示状态3“指南已生成，分类失败”和error_message，不能标记完整成功。单篇流式保持content编码约定，完成后发送complete或error。

## 阅读页面
复用统一GuideReader于导入预览及详情：Markdown安全渲染、自动目录锚点、完整报告、Mermaid严格模式、可见渲染错误。按窄屏调整布局，正文16px、适宜行宽，表格横向滚动，支持全屏。详情将文件信息折叠，提供原文抽屉、来源链接和文本搜索、报告导出及选中文本/当前章节创建笔记。历史Markdown也自动生成目录，不强制套新结构。

## 借鉴笔记
H2新增literature_note表，外键literature_id；字段title、category（WRITING/METHOD/IDEA/MATERIAL）、source_location、excerpt、reflection、create_time、update_time。API按文献读写、按文献与noteId联合定位修改删除；文献逻辑删除后拒绝读写笔记，保留底层笔记。输入在Controller以Bean Validation限制空值、枚举和长度。用户编辑个人思考，不将摘录自动写成个人研究事实。支持Markdown导出，包含文献、位置、摘录、个人备注。

## 技术约束
Java 21 / Spring Boot 3.5.5 / MyBatis-Plus / H2；Vue Composition API，Java四空格、JS两空格、单引号无分号。沿用com.literature包及现有业务异常。保留工作区其他改动，数据库增量DDL可重复执行，保留旧数据。只为安全渲染新增DOMPurify依赖。无静默回退或伪造成功。

## 验收
文件解析测试覆盖DOCX表格顺序、嵌套表格、PDF页序、Markdown结构、空文件；AI集成测试覆盖正常流、截断、缺结束事件、非JSON错误和分类失败；MVC+H2验证原文持久化、历史重解析、笔记CRUD、越界noteId、非法输入和逻辑删除。前端Node测试验证目录/证据链接/HTML过滤；生产构建及真实浏览器验证目录、原文搜索、笔记保存刷新修改删除、导出、移动端和渲染错误。真实模型质量需真实文献与API执行，本地协议测试不能证明内容质量。
